# Thoth — Your project's memory.

Thoth is a local-first project memory app backed by SQLite.

Core features
- Dashboard (users, activity, project status)
- Markdown notes
- Kanban (New, Urgent, In Progress, Testing, Resolved, For Deployment, Closed, Reopened)
- Tasks & Bugs (detailed bug reports, attachments, comments)
- Calendar, Workspaces, Milestones, Reports, Settings

Docs & previews
- docs/app_overview.txt — textual app overview
- docs/projects_preview.html — Projects UI preview
- docs/dashboard_preview.html, docs/kanban_preview.html, docs/bugs_preview.html, docs/reports_preview.html — additional previews
