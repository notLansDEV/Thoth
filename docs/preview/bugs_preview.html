RESOLVED-91 BUG

Write lock not released on transaction timeout

Resolved Critical
Reporter
M Marcus Webb
Project
Thoth Core
Module
Node.js, SQLite 3.45, Linux
Created
2026-08-19 01:45
Description

When a SQLite transaction exceeds the configured timeout, the write lock is not properly released, causing subsequent writes to hang indefinitely.

Steps to Reproduce
  1. Begin a write transaction
  2. Simulate timeout by delaying SQL
  3. Attempt subsequent write
  4. Observe indefinite hang
EXPECTED
Lock is released after timeout and subsequent writes proceed normally.
ACTUAL
Subsequent write operations block forever until process restart.
