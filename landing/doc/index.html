Get started with Thoth

Thoth is a self-hosted project management and knowledge workspace. Deploy it with Docker, create your workspace, and start managing projects, tasks, bugs, milestones, reports, and Markdown notes in one place.

Quick Start

Run the all-in-one Docker image with a persistent data volume.

Self-Hosted

Keep your data on your own server with simple Docker-based deployment.

Docker Quick Start

The fastest way to run Thoth is the all-in-one image. It includes the app and bundled PostgreSQL storage.

docker run -d --name thoth \
  -p 5232:5232 \
  -v ~/.thoth:/var/opt/thoth \
  ghcr.io/notlansdev/thoth:latest

Then open http://localhost:5232.

Data persistence: The ~/.thoth volume stores your database and app data. Keep it safe before removing containers or upgrading.

Docker Compose

For a standard app + Postgres setup, use Docker Compose from the repository.

git clone https://github.com/notLansDEV/Thoth.git
cd Thoth
cp .env.example .env
# Edit .env with secure values

docker compose up -d --build

The app will be available at http://localhost:5232 by default.

Configuration

Configure Thoth using environment variables. For production, set strong secrets and review your database/CORS settings.

Common environment variables

# App
PORT=5232
NODE_ENV=production
JWT_SECRET=replace-with-a-long-random-secret

# Database
DATABASE_URL=postgresql://user:password@host:5432/thoth

# Optional
CORS_ORIGIN=https://your-domain.example
Security: Do not use default secrets in production. Set a strong JWT_SECRET and protect your database credentials.

Updating

Back up your data before updating. For the all-in-one Docker image:

docker pull ghcr.io/notlansdev/thoth:latest
docker rm -f thoth
docker run -d --name thoth \
  -p 5232:5232 \
  -v ~/.thoth:/var/opt/thoth \
  ghcr.io/notlansdev/thoth:latest

For Compose deployments, pull/build the latest changes and restart with docker compose up -d --build.

Backup & Restore

Your Thoth data lives in the configured database/storage volume. Before upgrades or migrations, create a backup.

All-in-one image

Back up the mounted data directory:

cp -r ~/.thoth ~/.thoth-backup-$(date +%Y%m%d)

PostgreSQL

If using an external Postgres database, use standard Postgres backup tools such as pg_dump and restore with psql/pg_restore.

FAQ

What port does Thoth use?

By default, Thoth listens on port 5232. You can map it to another host port with Docker, for example -p 8080:5232.

Where is my data stored?

In the all-in-one Docker setup, data is stored in the mounted volume (example: ~/.thoth). In Compose/custom setups, data is stored in your configured PostgreSQL database and any configured storage volumes.

Is Thoth self-hosted?

Yes. Thoth is designed to run on your own server or machine using Docker.

How do I update to the latest version?

Pull the latest image, recreate the container, and keep your data volume mounted. Always back up your data before updating.

Why can't I log in or create an account?

Check that the app is healthy, the database is reachable, and your environment variables are configured correctly. For production, ensure JWT_SECRET is set and reverse proxy/CORS settings match your domain.

How do I report a bug or request a feature?

Open an issue on the Thoth GitHub repository.
